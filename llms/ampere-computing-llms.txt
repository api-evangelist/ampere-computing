# Ampere Computing

> Santa Clara, California semiconductor company founded in 2018 by Renee James and now part of the
> SoftBank Group. Ampere designs Arm-based Cloud Native Processors — the Ampere Altra / Altra Max
> families (up to 128 cores) and the flagship AmpereOne family (up to 192 single-threaded cores) —
> for cloud, AI inference and edge deployments, and ships an accompanying software stack of Ampere
> Optimized AI frameworks, tuned toolchains and performance/porting tooling.

IMPORTANT FOR AGENTS: Ampere Computing publishes **no public API**. There is no OpenAPI, AsyncAPI,
GraphQL SDL, MCP server, agent card, SDK, webhook catalog or API key programme. Its "Developer"
surface is a hardware, tooling and porting programme, not an API programme. Do not attempt to call
an Ampere API — none is documented. This file was generated by API Evangelist from public pages;
